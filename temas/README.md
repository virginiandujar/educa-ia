# Temas

Este directorio es el índice editorial del proyecto. Cada tema debe incluir, como mínimo:

1. Un `README.md` autocontenido.
2. Un objetivo de aprendizaje.
3. Ideas clave y ejemplos.
4. Preguntas para abrir conversación.
5. Notas para quien presente el contenido.
