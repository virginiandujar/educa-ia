# Ejemplos

Este directorio separa dos conceptos que se confunden con frecuencia:

| Ejemplo | Usa un modelo | Decide herramientas | Qué demuestra |
|---|---:|---:|---|
| [Generador determinista](agente-creador-proyectos/README.md) | No | No | Una automatización segura basada en una orden fija. |
| [Agente de IA](agente-ia-creador-proyectos/README.md) | Sí | Sí | Un modelo que planifica, usa herramientas, observa resultados y puede corregir. |

La parte que modifica archivos es determinista y limitada en los dos casos. La diferencia está en quién interpreta la petición y decide el siguiente paso.
